# Design

Palette from the live BlinkMoney app. Layout is a rebuild, not a screenshot clone.

- Background `#000000`. Surfaces `#141414` / `#1C1C1C`. Text off-white, muted `#8A8A82`.
- Accent `#A3E635` on the CTA, the active tab, and the number that matters. Not as a stroke on every card.
- Danger / logout: coral `#E07A5F`.
- Sans (DM Sans) for chrome. Serif (Fraunces) for titles and rupee figures.
- Indian grouping: `₹18,400`. Never `0 INR`.
- Rates and 15% p.a. always carry * / T&C once, not as wallpaper.

Tabs: Home, Save, Stress, Borrow, Rewards. Profile is a stack screen from the Home avatar.

Help is one control (WhatsApp), not a lime billboard on every tab.
